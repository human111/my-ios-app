#  Xcode快捷键

Xcode使用技巧：https://www.youtube.com/watch?v=um5OgZpGC-U

## 问题一：在使用时，Xcode的怎么快速切换到基本例子的写法，因为根据提示词选中后，会直接出现Button(role: <#T##ButtonRole?#>, action: <#T##() -> Void#>, label: <#T##() -> View#>)的代码，写的时候需要一个一个改

这是 Xcode 补全的常见痛点。有几种办法可以快速得到尾随闭包的写法。

### 方法一：在补全列表里选对的那一项（最推荐）

输入 `Button` 后，补全列表里会有**好几个** `Button` 的初始化方法，不要直接按回车选第一个，而是用上下方向键找到带 `action` 和 `label` 的那一项：

- `Button(action: () -> Void, label: () -> View)`：没有 role，参数最少
- `Button(role:action:label:)`：带 role 的完整版
- `Button(_ titleKey:action:)`：直接传文字的简洁版

选中后**按回车**，Xcode 会直接生成尾随闭包的形式：

```swift
Button {
    <#code#>
} label: {
    <#code#>
}
```

如果补全项旁边显示的是 `Button { } label: { }` 这种样式，就是你要的。

### 方法二：输入时加上花括号触发

输入 `Button` 后，直接敲 `{` 再回车，Xcode 会把它识别成尾随闭包写法，自动匹配只有 `action` 和 `label` 的那个初始化方法。

### 方法三：用占位符快速跳转和删除

如果已经生成了带 `<#T##...#>` 的完整版，不用手动一个个选中删除：

- **`Tab`**：跳到下一个占位符
- **`Shift + Tab`**：跳回上一个占位符
- 占位符被选中时，**直接输入**就会替换它
- 选中整个占位符后按 **`Delete`** 可以删掉内容

占位符是一个整体，光标落在上面时点一下就是整块选中，不需要逐字删除。

### 方法四：自定义代码片段（Code Snippet）

如果你经常用某种固定写法，可以自己做一个快捷输入：

1. 先在代码里写出你想要的完整形式：

```swift
Button {
    <#code#>
} label: {
    <#label#>
}
```

2. 选中这段代码，右键选择 **Create Code Snippet**（或在 Xcode 右上角的 **+** 菜单，打开 Library，进入 Snippets 页签）
3. 给它设置一个 **Completion**（补全缩写），比如 `btn`
4. 以后输入 `btn` 回车，就会生成你预设的模板

你甚至可以做多个，比如 `btnr` 对应带 role 的版本。

### 方法五：如果标签只是文字

最快的是直接用文字版，输入 `Button("` 开头，补全会生成：

```swift
Button("<#titleKey#>") {
    <#code#>
}
```

### 小结

| 想要的写法 | 操作 |
|---|---|
| 尾随闭包 `Button { } label: { }` | 补全列表中选**无 role** 的那一项，或输入 `Button {` |
| 文字按钮 `Button("x") { }` | 输入 `Button("` |
| 带 role | 选带 `role` 的那一项，再用 `Tab` 在占位符间跳转 |
| 固定常用模板 | 创建 Code Snippet |

日常使用中，**方法一加 Tab 跳转**基本就够了，用熟之后几乎不需要手动改。


## 问题二：在当前文件中，同时修改同一个变量

Xcode 里有两种常用方式：**同时编辑多个相同的变量**（Edit All in Scope）和**真正的重构重命名**（Rename）。

### 方法一：Edit All in Scope（最常用）

**快捷键：`Control + Command + E`**

1. 把光标放在变量名上（或双击选中它）
2. 按 `Control + Command + E`
3. 当前**作用域内**所有同名变量都会高亮，直接输入新名字，所有地方同步修改

这是你问的"同时修改"最直接的方式。

**注意**：它只在当前作用域内生效，而且是**文本层面**的替换。比如在函数里用它，只会改这个函数内的同名变量，不会影响函数外的。如果想改整个文件里的，要把光标放在类型或属性的定义处，作用域更大。

### 方法二：Rename 重构（更安全）

**快捷键：`Control + Command + R`**（Xcode 15 起，在较新版本里也可以用右键菜单）

或者：右键变量名 → **Refactor** → **Rename…**

1. 光标放在变量名上
2. 右键选 **Refactor → Rename…**
3. 输入新名字，回车确认

它是**语义层面**的重命名，Xcode 会理解代码结构，能够：
- 跨文件修改所有引用
- 不会误改同名但不同含义的变量
- 同时更新属性、方法调用、SwiftUI 里的绑定

**注意**：`Control + Command + R` 在某些版本里可能没有默认绑定，如果不生效，用右键菜单或者去 **Settings → Key Bindings** 里搜索 "Rename" 自己设置。

### 方法三：多光标编辑

**快捷键：`Control + Shift + 鼠标点击`**

按住这两个键，在多个位置点击，会出现多个光标，然后一起输入或删除。适合你想手动挑选要改的位置，而不是改全部。

### 方法四：查找替换

**快捷键：`Command + F`**（文件内查找），再点击左边的放大镜图标，切换到 **Replace** 模式。

- 可以逐个替换，也可以全部替换
- 想跨文件，用 `Command + Shift + F`
- 缺点是纯文本匹配，容易误改，比如把 `count` 替换时，`accountCount` 里的 `count` 也可能被改

### 对比总结

| 需求 | 方式 | 快捷键 |
|---|---|---|
| 当前作用域内同步改 | Edit All in Scope | `Control + Command + E` |
| 安全重命名，跨文件 | Refactor → Rename | 右键菜单，或 `Control + Command + R` |
| 手动挑选多处同时改 | 多光标 | `Control + Shift + 点击` |
| 按文本批量替换 | Find & Replace | `Command + F` |

日常开发推荐：**小范围改名用 `Control + Command + E`，重要的变量或属性名用 Refactor → Rename**，更不容易出错。


## Xcode选中相同变量的快捷键

### 选中相同变量(多光标/同步编辑)

#### 最常用:`⌃⌘E`(Edit All in Scope)

光标放在变量名上(或选中变量名),按 `⌃⌘E`,会选中**当前作用域内**所有同名变量,可以同时修改。

- 作用域指当前函数/类等范围,不会改到其他文件
- 修改后按 `Esc` 或点击别处退出

#### 逐个选中下一个相同项

Xcode 没有 VS Code `⌘D` 那种"逐个添加下一个匹配"的原生功能,可以用这些替代:

- **查找下一个**:选中变量后按 `⌘E`(把选中内容设为查找内容),再按 `⌘G` 跳到下一个,`⇧⌘G` 跳到上一个
- **多光标**:按住 `⌃⇧` 再点击多个位置,可以同时编辑多处

#### 跨文件/全项目重命名

右键变量 → **Refactor → Rename...**(快捷键 `⌃⌘R`,部分版本需自行绑定)

- 会同时修改所有引用,包括其他文件
- 会弹出预览,确认后统一改名
- 比 `⌃⌘E` 更安全,因为它理解语法,不会误改同名但不同含义的东西

#### 高亮显示相同变量

点击变量名后,Xcode 会自动高亮同名符号。如果没高亮,检查 **Settings → Text Editing → Display → Highlight** 相关选项。

#### 对比

| 需求 | 快捷键 |
|------|--------|
| 当前作用域内同时改名 | `⌃⌘E` |
| 全项目安全重命名 | Refactor → Rename |
| 逐个查找跳转 | `⌘E` + `⌘G` |
| 手动多光标 | `⌃⇧` + 点击 |

最接近 VS Code 体验的是 `⌃⌘E`,日常改局部变量名基本够用。

## xcode 类似vscode中的command+d

Xcode 原生**没有**和 VS Code `⌘D` 完全一样的"逐个追加选中下一个相同项"功能。我之前提到的 `⌘E` + `⌘G` 只是查找跳转,不会形成多选。不过有两种方式可以接近:

### 方法一:`⌃⌘E`(一次选中全部)

光标放在变量上,按 `⌃⌘E`,选中当前作用域内所有相同变量,同时编辑。适合"全改"的场景,但不能像 `⌘D` 那样挑着选。

### 方法二:手动多光标

按住 `⌃⇧`,然后依次点击(或拖选)想编辑的位置,可以手动逐个添加光标。虽然要用鼠标,但能精确挑选哪几个要改。

### 方法三:用 Edit All in Scope 之后再取消不要的

目前没有原生方式在选中全部后取消其中某几个,所以这个方法不太实用。

### 想要真正的 `⌘D` 效果

只能借助第三方:

- **Xcode 的 Vim 模式**(Settings → Text Editing → Editing → Enable Vim mode)配合 `*` / `n` 跳转,但不是多光标
- 一些 Source Editor Extension 可能提供类似功能,但兼容性和维护情况因 Xcode 版本而异,建议自行查证
- 如果你很依赖多光标编辑,可以把这类大范围修改放到 VS Code 里做,Xcode 只负责编译和调试

### 日常替代建议

| 场景 | 做法 |
|------|------|
| 改某变量的全部出现位置 | `⌃⌘E` |
| 改变量名(含跨文件) | Refactor → Rename |
| 只改其中几处 | `⌃⇧` + 点击 |
| 只想跳转查看 | `⌘E` + `⌘G` |
