#  Codable自动生成代码

Add Explicit Codable Implementation，是因为它被放在了 Refactor 二级菜单中，而不是右键菜单的一级菜单。

以后操作步骤就是：
1. 光标放在 struct 类型名称上。
2. 右键（Control + Click）。
3. 找到 Refactor。
4. 展开二级菜单。
5. 选择 Add Explicit Codable Implementation。

重点掌握 Xcode 这些自动代码生成能力：
- Add Explicit Codable Implementation：展开 Codable 实现。
- Generate Memberwise Initializer：生成成员初始化器。
- Add Documentation：生成文档注释。
- Rename：安全重命名。
- Extract to Method：提取方法（如果当前上下文支持）。
